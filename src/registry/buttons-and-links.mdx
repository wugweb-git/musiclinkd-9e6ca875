# Buttons and links

The system, then every hand-styled button or link that does not use it yet. Generated from the code on 16 Sep 2026; rerun the inventory script to refresh.

## The system

| Type                         | Component           | Variants                                                                                                 | Stories                    |
| ---------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------- |
| Button: label                | `Btn`               | `primary` (ink fill), `outline` (card + border), `ghost` (grey fill), `ink` (same as primary: duplicate) | Primitives/Btn             |
| Button: label with icon      | `Btn icon={…}`      | as above, icon leads                                                                                     | Primitives/Btn → With icon |
| Button: icon only            | `IconBtn label="…"` | `outline`, `ink`, `ghost`, `plain`                                                                       | Primitives/Btn → IconBtn   |
| Link as button               | `BtnLink`           | as `Btn`                                                                                                 | Primitives/Links           |
| Link as icon button          | `IconBtnLink`       | as `IconBtn`                                                                                             | Primitives/Links           |
| Text link                    | `AuthLink`          | one look; `icon` optional                                                                                | Primitives/Links           |
| Text action (not navigation) | `AuthTextButton`    | enabled, disabled                                                                                        | Primitives/Links           |

**Button states:** default, hover and pressed overlay (`state-layer`), press shrink, touch ripple, focus ring, disabled, pending (looks disabled, still takes the tap), loading (spinner, `aria-busy`).

**Text link states:** default, hover underline, pressed dim, 48dp touch area. No focus style of its own beyond the global ring, no loading.

**Not in the system yet:** a text-only tertiary `Btn`, a small button size, a general (non-auth) text link name.
